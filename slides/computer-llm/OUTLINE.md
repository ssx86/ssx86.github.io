### P10 · 大模型一次运行 = 输入一段 → 输出一段（回主轴）
- **布局**：标题 + `.arrow-illustration`
- **图形**：输入"你好"（粉框）→ 🤖大模型 → 输出"你好！"（蓝框）

  - h2："大模型，也是一种'输入→输出'的盒子"
  - lede："和前面的程序一样：输入文字，输出文字。只是它的'加工'方式特别——靠续字"
- **底栏**：大模型 = 输入文字 → 输出文字 · 10/38
- **逐字稿要点**：现在我们把大模型装回一开始那个"盒子"框架。它也是一种"输入→输出"的盒子：你输入文字，它输出文字。只不过它的加工方式很特别——靠续下一个字。所以大模型本质上也是一种程序，只是它和人写死的程序不一样，它的"菜谱"不是人写死的，是自己学出来的。

- **底栏**：容量有限 → 太久的事会忘 · 12/38

## C 段 · 它的能力边界——为什么会胡说（P13–P15）

- **布局**：标题 + 居中流程图
- **图形**：📚整个互联网的文字 → 🔧训练 → 🧠大模型。中间标注"记住'什么词后面常跟什么'"
- **文字**：

  - h2："它的本事从哪来：训练"
  - lede："把'读过'整个互联网、记住词与词怎么搭配的过程，叫'训练'"

- **审核修复**：纠正"训练"人格化(⚪25)，为"规律≠事实"铺路
- **逐字稿要点**：上一页说它"读过"很多东西有了直觉，这个过程有个名字叫"训练"。但要注意——它"读"不像人那样去理解内容，它只是记住了"哪些词经常挨在一起"这种规律。记住这一点，下一页你就懂它为什么会胡说。

### P14 · 它懂"规律"不懂"事实" → 会胡说（补一正一反例子）
- **布局**：标题 + `.two-col`（正反对比）

  - 右框 ❌："问它「苏轼的妹妹叫什么？」→ 它言之凿凿编出「苏小妹，嫁给了秦观……」（历史上根本没有苏小妹）"
- **文字**：
  - kicker："第四课 · 它的边界"
  - h2："它给的是'最可能的字'，不是'事实'"
  - lede："所以它会一本正经地胡说八道"
  - 消歧术语："AI 圈把这种一本正经胡说叫'幻觉'——注意，和人生病的幻觉不是一回事，只是借用了这个词"
- **底栏**：规律 ≠ 事实 → 会"幻觉" · 14/38
- **审核修复**：补一正一反例子搭桥(🔵9)、消歧"幻觉"(🟢18)
- **逐字稿要点**：它只记规律，不记事实。比如它知道"故宫在"后面常跟"北京"，所以填"北京"——这是对的。但如果你问它一个它没见过的冷知识，它也会照"最顺口的接法"填一个看起来像答案的东西——这就错了。AI 圈管这叫"幻觉"，和人生病的幻觉不是一回事，只是借用了这个词。

- **底栏**：你的语气 = 它的输入 → 它会顺着接 · 15/38
- **审核修复**：开头连回接龙机理(🔵10)、改直白措辞(⚪22)
